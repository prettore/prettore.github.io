# Inteligência Artificial — aulas

Pasta estática do portal para `lectures-notes/ia/`, organizada em índice, três blocos, CSS, assets próprios e notas originais.

- `index.html`: índice das sete aulas.
- `bloco1/`, `bloco2/`, `bloco3/`: páginas HTML das aulas.
- `css/`: estilo-base e ajustes de IA.
- `assets/`: logo local e scripts das apresentações.
- `notas/`: PDFs originais com nomes preservados.

Extraia o ZIP na raiz do repositório `prettore.github.io`; a pasta `lectures-notes/ia/` não depende dos arquivos locais de `lectures-notes/ialg/`. Para manter a estrutura simples como no IAlg, Reveal.js 4.3.1 e as fontes do tema são carregados de CDN. Portanto, os slides precisam de conexão à internet para carregar o Reveal.js e as fontes.
