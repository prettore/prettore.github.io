🧮 Aula 07 — Matrizes

Uma matriz organiza valores do mesmo tipo em linhas e colunas. Pense em uma tabela de notas ou assentos.

int notas[2][3] = {
    {8, 7, 9},
    {6, 10, 8}
};

for (int linha = 0; linha < 2; linha++) {
    for (int coluna = 0; coluna < 3; coluna++)
        cout << notas[linha][coluna] << ' ';
    cout << '\n';
}

O primeiro índice escolhe a linha; o segundo, a coluna. Os índices começam em zero.

🔤 Aula 08 — Strings guardam texto

string

Representa uma sequência de caracteres e pode guardar nomes, títulos e descrições.

string titulo = "Algoritmos";
cout << titulo.length();

Texto completo

cin >> para no espaço; getline() lê a linha inteira, incluindo espaços.

string nome;
getline(cin, nome);

Ao ler um número com cin antes de chamar getline(), descarte o \n pendente com cin.ignore().

⌨️ Exemplo: número e linha completa

int codigo;
string titulo;

cin >> codigo;
cin.ignore();
getline(cin, titulo);

cout << codigo << " — " << titulo << '\n';
  • cin lê o campo numérico.
  • ignore() consome o fim da linha anterior.
  • getline() captura o texto com espaços.

Neste exemplo, cin.ignore() descarta o \n deixado por cin antes de getline().

📍 Aula 09 — Ponteiro: endereço e acesso

Um ponteiro guarda o endereço de outra variável. O operador * acessa o valor guardado naquele endereço.

Variável

int quantidade = 3;

Endereço

int* p = &quantidade;

Indireção

*p = 4; altera quantidade.

Use um ponteiro somente quando ele aponta para uma região válida. Depois de liberar a memória, não use o endereço antigo.

🧱 Alocação dinâmica

Com new[], o programa solicita espaço durante a execução. A capacidade pode ser decidida enquanto o programa roda.

int capacidade = 2;
int quantidade = 0;
Livro* livros = new Livro[capacidade];

// ... usar livros[0] e livros[1]

delete[] livros;

Quantidade = posições preenchidas. Capacidade = posições reservadas. Um vetor criado com new[] deve ser liberado com delete[].

🔎 Busca binária: metade por vez

Ela exige que os dados estejam ordenados pela chave pesquisada. Cada comparação descarta metade do intervalo.

1. Meio

[10, 20, 30, 40, 50, 60]
meio = 30

2. Direita

Procuramos 50.
30 < 50 → descarta a esquerda.

3. Encontrou

Novo meio = 50.
Chave localizada.

Se o vetor estiver fora de ordem, a decisão de descartar metade pode eliminar a resposta correta.

🔁 Recursão: resolver uma parte menor

Caso-base

Uma condição que encerra as chamadas. No fatorial, fatorial(1) vale 1.

Passo recursivo

A função chama a si mesma com um problema menor: n - 1.

int fatorial(int n) {
    if (n <= 1) return 1;       // caso-base
    return n * fatorial(n - 1);  // passo recursivo
}

A busca binária do exercício será iterativa, sem chamadas recursivas.

🧾 Aula 10 — Registros

Um registro agrupa campos relacionados, mesmo quando os campos têm tipos diferentes.

struct Livro {
    int codigo;
    string titulo;
};

Livro livro;
livro.codigo = 42;
livro.titulo = "A vida de Ada Lovelace";

Um vetor de registros guarda muitos itens com o mesmo formato: Livro livros[capacidade]. A posição escolhe um livro; o campo escolhe uma informação.

2. Copiar

if (quantidade == capacidade) {

🧩 Desafio: um catálogo de livros

Faça um programa de console que cadastra, lista e procura livros pelo código.

  • Cada livro tem código e título; o título pode conter espaços.
  • Armazene os registros em um vetor alocado dinamicamente.
  • Comece com capacidade 2 e dobre-a quando o vetor encher.
  • Para este exercício, cadastre os códigos em ordem crescente, por exemplo: 10, 20, 30.
  • Use busca binária iterativa para procurar um código.

Vamos montar o programa em pequenos trechos. Copie cada bloco no local indicado; compile e teste ao terminar a sequência.

🧩 Código — Passo 1A: estrutura e menu

Comece o programa com as bibliotecas, o registro Livro e a função do menu.

#include <iostream>
#include <string>
using namespace std;

struct Livro {
    int codigo;
    string titulo;
};

void mostrarMenu() {
    cout << "1-Cadastrar  2-Listar  3-Buscar  0-Sair\n";
}

Essas definições ficam antes de main(). No próximo slide, vamos acrescentar os procedimentos.

🧩 Código — Passo 1B: leitura e listagem

Continue o arquivo, logo depois da função mostrarMenu().

void lerLivro(Livro& livro) {
    cout << "Codigo: ";
    cin >> livro.codigo;
    cin.ignore();
    cout << "Titulo: ";
    getline(cin, livro.titulo);
}

void listarLivros(const Livro livros[], int quantidade) {
    for (int i = 0; i < quantidade; i++)
        cout << livros[i].codigo << " - "
             << livros[i].titulo << '\n';
}

lerLivro preenche um registro e getline() guarda o título completo. Use os botões A− e A+ no canto inferior esquerdo para ajustar o tamanho do código.

📦 Código — Passo 2: função de redimensionamento

Adicione a função abaixo antes de main().

Livro* redimensionar(Livro* livros, int quantidade,
                     int& capacidade) {
    int novaCapacidade = capacidade * 2;
    Livro* maior = new Livro[novaCapacidade];

    for (int i = 0; i < quantidade; i++)
        maior[i] = livros[i];

    delete[] livros;
    capacidade = novaCapacidade;
    return maior;
}

Recebe

Vetor atual e quantidade usada.

Atualiza

capacidade por referência.

Devolve

O novo endereço do vetor.

🔍 Código — Passo 3: busca binária iterativa

Adicione antes de main(). As variáveis inicio e fim delimitam a parte ainda examinada.

int buscaBinaria(const Livro livros[], int quantidade,
                 int codigo) {
    int inicio = 0;
    int fim = quantidade - 1;

    while (inicio <= fim) {
        int meio = inicio + (fim - inicio) / 2;
        if (livros[meio].codigo == codigo) return meio;

        if (codigo < livros[meio].codigo)
            fim = meio - 1;
        else
            inicio = meio + 1;
    }
    return -1;
}

A cada repetição, o intervalo fica menor. Para funcionar, os códigos precisam estar em ordem crescente.

🧱 Código — Passo 4: iniciar o programa

Agora escreva main(). No próximo passo, preencheremos o ponto indicado com as opções.

int main() {
    int capacidade = 2;
    int quantidade = 0;
    Livro* livros = new Livro[capacidade];
    int opcao;

    do {
        mostrarMenu();
        cin >> opcao;

        // Os blocos dos passos 5 e 6 entram aqui.

    } while (opcao != 0);

    delete[] livros;
    return 0;
}

O vetor nasce com duas posições. A memória será liberada ao encerrar.

➕ Código — Passo 5: cadastrar e crescer

Dentro do do de main(), logo após cin >> opcao;, substitua o comentário por este bloco.

if (opcao == 1) {
    if (quantidade == capacidade)
        livros = redimensionar(livros, quantidade,
                               capacidade);

    Livro novo;
    lerLivro(novo);
    livros[quantidade] = novo;
    quantidade++;
}

Digite os códigos em ordem crescente para manter o vetor pronto para a busca binária. Quando o vetor enche, ele é ampliado antes do novo cadastro.

🔎 Código — Passo 6: listar e buscar

Logo depois do } do cadastro, ainda dentro do do, acrescente os casos seguintes.

else if (opcao == 2) {
    listarLivros(livros, quantidade);
} else if (opcao == 3) {
    int codigo;
    cout << "Codigo procurado: ";
    cin >> codigo;
    int pos = buscaBinaria(livros, quantidade, codigo);
    if (pos == -1) cout << "Nao encontrado\n";
    else cout << livros[pos].titulo << '\n';
} else if (opcao != 0) {
    cout << "Opcao invalida\n";
}

A busca retorna o índice encontrado ou -1 quando o código não aparece.

🧪 Teste de mesa: o que deve acontecer?

Cadastros

Comece com capacidade 2. Digite os códigos 10 e 20; ao cadastrar 30, o vetor cresce para capacidade 4.

Os dados ficam [10, 20, 30], na ordem digitada.

Busca

Procure 20. O meio é a posição 1 e a chave é encontrada.

Procure 99. O intervalo diminui até ficar vazio; a função retorna -1.

Teste também títulos com espaços, por exemplo: Estruturas de Dados.

✅ Checklist para revisar

  • getline() lê o título inteiro; ignore() remove a quebra pendente.
  • new[] aloca o vetor; delete[] libera a mesma alocação.
  • Digite os códigos em ordem crescente para que a busca binária funcione.
  • A busca binária iterativa atualiza inicio ou fim a cada repetição.
  • Na recursão, o caso-base encerra as chamadas e cada passo reduz o problema.
  • Ao redimensionar, copie apenas quantidade registros e guarde o novo ponteiro.

Erros frequentes: buscar em dados fora de ordem, esquecer a capacidade, usar o ponteiro antigo depois de delete[] ou liberar com delete em vez de delete[].
