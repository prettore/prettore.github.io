🎯 Texto em C++

Uma string representa uma sequência de caracteres. Ela é prática para nomes, frases e mensagens.

Palavra

string nome = "Ana";

Frase

Também pode conter espaços.

Caracteres

Cada posição tem um índice.

Inclua <string> e use std::string ou using namespace std.

🔤 Strings × vetores de caracteres

string

Tipo da biblioteca C++ para textos. Conhece seu tamanho e oferece funções como find() e replace().

char[]

Vetor de caracteres. Para representar uma C-string, precisa terminar com o caractere nulo \0.

char letras1[4] = {'i', 'a', 'l', 'g'};       // vetor de char
char letras2[5] = {'i', 'a', 'l', 'g', '\0'};  // C-string

Sem \0, o vetor não informa onde o texto termina. Para as atividades da disciplina, prefira string quando não houver motivo para usar char[].

📏 Tamanho da sequência de caracteres

length()

Quantidade de caracteres da string.

size()

Faz a mesma contagem em uma string.

strlen()

Conta uma C-string até encontrar \0.

#include <cstring>

string nome = "IAlg";
char palavra[] = "UFLA";

cout << nome.length();   // 4
cout << nome.size();     // 4
cout << strlen(palavra); // 4

length() e size() são métodos de string; strlen() é uma função para vetores de caracteres terminados em \0.

🧰 Biblioteca <string>

Além de guardar texto, string oferece operações para localizar, remover e substituir partes da sequência.

#include <string>

std::string frase = "IAlg em C++";
size_t pos = frase.find("C++");
if (pos != std::string::npos)
    cout << "Encontrado na posição " << pos;

frase.replace(0, 4, "Aula"); // substitui "IAlg" por "Aula"
frase.erase(4, 3);            // remove " em"

Como interpretar: replace(posição, quantidade, novo texto). Como "IAlg" tem 4 caracteres, replace(0, 4, "Aula") produz "Aula em C++". Usar 0, 3 deixaria o g no texto.

find()

Busca um trecho e retorna sua posição.

erase()

Remove caracteres a partir de uma posição.

replace()

Troca um trecho por outro.

🔎 Quando a busca não encontra?

Funções como find() retornam uma posição quando encontram o trecho. Quando não encontram, retornam o marcador especial std::string::npos.

std::string frase = "IAlg em C++";
size_t pos = frase.find("Python");

if (pos == std::string::npos)
    cout << "Trecho não encontrado";

Encontrou

pos recebe um índice válido: 0, 1, 2...

Não encontrou

pos recebe std::string::npos, uma constante que significa “posição inexistente”.

Use pos != std::string::npos para testar sucesso. Não dependa do número interno da constante e não compare diretamente com -1.

⌨️ cin lê até o espaço

string nome;
cin >> nome;

Se a entrada for Paulo Rettore, o cin lê apenas Paulo.

O operador >> pula espaços no início e para no próximo espaço. Para ler uma linha inteira, use getline().

📖 getline() lê a linha inteira

string frase;
getline(cin, frase);
cout << frase;

getline() lê até a quebra de linha e preserva os espaços internos.

Entrada

Paulo Rettore

Leitura

getline()

Resultado

nome completo

⚠️ O problema do \n no buffer

int idade;
string nome;

cin >> idade;
getline(cin, nome); // pode ler vazio

Depois de cin >>, a quebra de linha pode permanecer no buffer. O getline() encontra essa quebra imediatamente.

🛠️ A correção com cin.ignore()

#include <limits>

int idade;
string nome;

cin >> idade;
cin.ignore(numeric_limits<streamsize>::max(), '\n');
getline(cin, nome);

Descartamos tudo até o fim da linha antes de ler o nome completo. Para uma entrada simples, cin.ignore() também pode ser suficiente.

🧩 Leitura com separadores

O terceiro argumento de getline() define o delimitador. A leitura termina no separador, que é consumido e não entra no texto.

string nome, cidade;

// Entrada: Ana Silva;Lavras
getline(cin, nome, ';');
getline(cin, cidade);       // até o fim da linha

cout << nome << " mora em " << cidade;

A mesma ideia funciona com cin, ifstream e stringstream. Use o delimitador que o arquivo realmente utiliza: ';', ',' ou outro.

📦 O que são <sstream> e stringstream?

#include <sstream>

Inclui as classes que tratam uma string como um fluxo de entrada e saída, usando a memória do programa.

stringstream

É um objeto que recebe uma string e permite ler seus dados aos poucos, usando >> ou getline().

#include <sstream>

std::string linha = "Ana Silva;20;8.5";
std::stringstream campos(linha);

stringstream não abre arquivo e não lê diretamente do teclado: ele organiza uma string que já está na memória para que possamos extrair e converter seus campos.

🧪 Separando uma linha CSV

#include <sstream>

string linha = "Ana Silva;20;8.5";
stringstream campos(linha);
string nome, idadeTexto, notaTexto;

getline(campos, nome, ';');
getline(campos, idadeTexto, ';');
getline(campos, notaTexto);

int idade = stoi(idadeTexto);
double nota = stod(notaTexto);

Primeiro os campos são lidos como texto. Depois, stoi() e stod() convertem os números para os tipos necessários.

Cada getline(campos, ...) consome o próximo campo e avança o cursor do fluxo. Por isso, a segunda leitura começa depois do primeiro ;.

📚 Lendo um arquivo CSV

#include <fstream>
#include <sstream>

ifstream arquivo("alunos.csv");
if (!arquivo) return 1;

string linha;
getline(arquivo, linha); // descarta o cabeçalho
while (getline(arquivo, linha)) {
    stringstream campos(linha);
    string nome, idadeTexto, notaTexto;
    getline(campos, nome, ';');
    getline(campos, idadeTexto, ';');
    getline(campos, notaTexto);
    cout << nome << " — " << notaTexto << '\n';
}

Use a própria leitura no while. Assim o laço termina no fim do arquivo ou quando ocorre uma falha de leitura.

🧭 Cuidados com CSV

  • Confirme se o arquivo abriu antes de ler.
  • Identifique se o separador é ; ou ,.
  • Decida se a primeira linha é um cabeçalho e descarte-a quando necessário.
  • Verifique se todos os campos esperados foram encontrados antes de converter.
  • Use getline() para preservar espaços em nomes e descrições.

Um CSV não é necessariamente separado por vírgulas: no Brasil, o ponto e vírgula é comum quando a vírgula aparece em números decimais.

🔎 Percorrer uma string

string palavra = "algoritmo";
int vogais = 0;

for (int i = 0; i < palavra.size(); i++) {
    char c = palavra[i];
    if (c == 'a' or c == 'e' or c == 'i' or
        c == 'o' or c == 'u')
        vogais++;
}

Uma string pode ser percorrida como uma sequência de caracteres. O índice inicial é 0 e o último índice é size() - 1.

🧩 Desafio: cadastro simples

Leia a idade e o nome completo de uma pessoa. Depois, mostre uma mensagem de apresentação.

  1. Leia a idade com cin.
  2. Use cin.ignore() quando necessário.
  3. Leia o nome completo com getline().

Amplie o desafio: leia também cidade e curso em uma linha separada por ;.

🧩 Prática em aula

Leia uma linha no formato nome;cidade;curso e mostre cada campo em uma linha diferente.

Entrada: Maria Silva;Lavras;Engenharia

Saída esperada:
Nome: Maria Silva
Cidade: Lavras
Curso: Engenharia

Gabarito orientador: use getline(cin, campo, ';') para os dois primeiros campos e um getline(cin, campo) para o último.
