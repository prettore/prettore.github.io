🎯 Matrizes: linhas e colunas

Uma matriz organiza valores do mesmo tipo em duas dimensões: linha e coluna.

int notas[3][4];

O acesso usa dois índices: notas[linha][coluna].

🔢 Como ler os índices

Linhas

Primeiro índice

0 ... L-1

Colunas

Segundo índice

0 ... C-1

Elemento

Par de índices

m[i][j]

Em uma matriz 3 × 4, existem 3 linhas e 4 colunas.

🧱 Declaração e inicialização

int m[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};

cout << m[1][2]; // 60

A linha 1, coluna 2 contém 60. Os índices começam em zero.

🔁 Dois for percorrem a matriz

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        cout << m[i][j] << " ";
    }
    cout << "\n";
}

O for externo controla as linhas; o interno controla as colunas.

➕ Somar todos os elementos

int soma = 0;
for (int i = 0; i < L; i++) {
    for (int j = 0; j < C; j++) {
        soma += m[i][j];
    }
}

A mesma ideia serve para contar, buscar maior valor ou calcular médias.

↘️ Diagonal principal

for (int i = 0; i < N; i++)
    cout << m[i][i] << " ";

Em uma matriz quadrada, a diagonal principal usa posições em que linha == coluna.

Exemplo: m[0][0], m[1][1], m[2][2].

📚 Matriz como parâmetro

const int L = 2, C = 3;

void imprime(const int m[][C]) {
    for (int i = 0; i < L; i++)
        for (int j = 0; j < C; j++)
            cout << m[i][j];
}

O número de colunas precisa estar disponível para o compilador.

🧩 Desafio: soma por linha

Leia uma matriz 3 × 4 de notas e mostre a soma de cada linha.

  1. Use um for para escolher a linha.
  2. Zere a soma no início de cada linha.
  3. Use o segundo for para percorrer as colunas.

Uma matriz pode representar alunos × atividades, dias × horários ou pixels × posições.

🧩 Prática em aula

Leia uma matriz 3 × 3 e mostre a soma da diagonal principal.

Gabarito orientador: Use dois índices para a matriz e observe que a diagonal principal é formada pelas posições m[i][i].
