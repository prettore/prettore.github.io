📦 Atribuição coloca um valor na memória

=
Em C++, o operador de atribuição é o sinal de igualdade. Ele significa "recebe", e não "é igual a".
int idade; idade = 18; double altura = 1.72;

O lado direito é calculado primeiro; o resultado é então armazenado na variável que está à esquerda.

🔄 Uma nova atribuição substitui o valor

int pontos = 10; pontos = 25; pontos = pontos + 5;

Evolução da variável

10 → 25 → 30

Como funciona?

A expressão pontos = pontos + 5 usa o valor atual (25) para produzir e armazenar o novo valor (30).

🧮 Cinco operadores resolvem os cálculos

Operação Operador Exemplo Resultado
Soma + 8 + 2 10
Subtração - 8 - 2 6
Multiplicação * 8 * 2 16
Divisão / 8 / 2 4
Resto % 8 % 3 2

O operador de resto % trabalha exclusivamente com valores inteiros.

⚠️ Divisão inteira é uma armadilha comum

double a = 7 / 2; // a recebe 3.0 double b = 7.0 / 2; // b recebe 3.5

A operação é resolvida antes da atribuição. Se os dois operandos forem inteiros, o resultado da divisão também será inteiro.

Para manter a parte decimal, use pelo menos um operando de ponto flutuante (como 7.0 em vez de 7).

📝 Parênteses deixam a intenção explícita

double media = nota1 + nota2 / 2.0; // Incorreto para a média double media = (nota1 + nota2) / 2.0; // Correto

Ordem Básica

  1. Parênteses
  2. Multiplicação, divisão e resto
  3. Soma e subtração

Regra Prática

Quando houver dúvida sobre a ordem de execução, use parênteses.

🧭 Precedência: resolva na ordem certa

X = A + B - C / D A = 18, B = 7, C = 6, D = 2

Passo a passo

1. Substitua: X = 18 + 7 - 6 / 2

2. Divisão primeiro: X = 18 + 7 - 3

3. Da esquerda para a direita: X = 25 - 3 = 22

Resposta

X = 22

Multiplicação, divisão e resto vêm antes de soma e subtração.

⚡ Operador composto: +=

int x = 7; x += 3;

x += 3 é uma forma curta de escrever x = x + 3.

Antes

x = 7

Depois

x = 7 + 3 = 10

Resultado final: x = 10

🔢 Pós-incremento e pré-incremento

Pós-incremento: usa, depois aumenta

int x = 4, y = 1; int z = x++ + y++;

Primeiro: z = 4 + 1 = 5

Depois: x = 5 e y = 2

Pré-incremento: aumenta, depois usa

int x = 4, y = 1; int z = ++x + ++y;

Primeiro: x = 5 e y = 2

Depois: z = 5 + 2 = 7

Leia com atenção: x++ e ++x não produzem o mesmo valor dentro da expressão.

⚡ Atualizações de forma curta

Forma Longa

saldo = saldo + 50; contador = contador + 1;

Forma Curta

saldo += 50; contador++;

Também existem -=, *=, /=, %= e --.

A forma curta deve ser usada somente quando continuar clara para quem lê.

📚 A biblioteca cmath oferece cálculos prontos

#include <cmath> double raiz = sqrt(25.0); // 5.0 double potencia = pow(2, 3); // 8.0 double modulo = abs(-7.5); // 7.5
  • sqrt() : Raiz quadrada
  • pow() : Potenciação
  • abs() : Valor absoluto (módulo)
  • ceil() : Arredondamento para cima
  • floor() : Arredondamento para baixo

📤 cout apresenta mensagens e valores

int idade = 18; cout << "Idade: " << idade << '\n'; cout << "Dobro: " << idade * 2 << '\n';
  • Textos fixos ficam entre aspas duplas
  • Variáveis e expressões ficam fora das aspas
  • O operador << encadeia as informações
  • endl ou '\n' geram uma quebra de linha

📥 cin lê dados para variáveis

int idade; cout << "Digite sua idade: "; cin >> idade;

O operador >> envia o valor digitado pelo usuário para a variável.

⚠️ Sempre declare a variável antes de realizar a leitura!

📥 Uma leitura pode preencher várias variáveis

double nota1, nota2; cout << "Digite duas notas: "; cin >> nota1 >> nota2;
⌨️
Os valores podem ser separados por espaço ou por Enter na hora da digitação.
💬
Uma mensagem com cout antes da leitura ajuda o usuário a entender o que deve informar.

✨ Formatação torna a saída mais clara

#include <iomanip> double preco = 19.5; cout << fixed << setprecision(2); cout << "Preço: R$ " << preco << '\n';

Saída gerada: Preço: R$ 19.50

Use <iomanip>, fixed e setprecision quando a quantidade de casas decimais importar.

🛤️ A estrutura sequencial executa na ordem escrita

1. Ler os dados

↓

2. Calcular o resultado

↓

3. Exibir o resultado

Não há desvios nem repetições: cada instrução é executada uma vez, de cima para baixo.

Uma sequência incorreta pode gerar um resultado incorreto mesmo quando cada linha está sintaticamente correta.

💻 Exemplo completo: Média de duas notas

#include <iostream> #include <iomanip> using namespace std; int main() { double nota1, nota2; cout << "Digite duas notas: "; cin >> nota1 >> nota2; double media = (nota1 + nota2) / 2.0; cout << fixed << setprecision(1); cout << "Média: " << media << '\n'; return 0; }

📖 Leia o código como uma pequena história

No exemplo da média:

1. Entrada

cin recebe as duas notas informadas pelo usuário.

2. Processamento

A expressão calcula a média e armazena na variável.

3. Saída

cout apresenta o resultado formatado na tela.

Essa decomposição ajuda a planejar a solução antes de programar.

🔄 Trocar valores exige preservar a informação

Forma Incorreta

a = b; b = a;

O valor original de a é perdido na primeira atribuição.

Forma Correta

int auxiliar = a; a = b; b = auxiliar;

A variável auxiliar salva o valor antes de ser sobrescrito.

🧹 Código legível reduz erros

  • Use nomes claros: media, nota1, precoFinal.
  • Indente blocos de código de maneira consistente.
  • Escreva uma instrução por linha.
  • Comente a intenção, não o óbvio.
// Calcula a média aritmética das duas avaliações double media = (nota1 + nota2) / 2.0;

🚫 Cinco erros comuns para evitar

Erro Correção
Usar vírgula em decimal: 3,14 Usar ponto: 3.14
Ler antes de declarar a variável Declarar a variável primeiro
Trocar cin >> por cin << Usar >> na entrada
Colocar variável entre aspas no cout Deixar a variável fora das aspas
Esperar 3.5 da operação 7 / 2 Usar 7.0 / 2

🧩 Desafio: Preveja a saída

int a = 7; int b = 2; double x = a / b; double y = a / 2.0; a += 1; cout << a << " " << x << " " << y << '\n';

Antes de prosseguir, anote o valor final de a, x e y.

✅ Gabarito: Tipos mudam o resultado

Saída gerada: 8 3 3.5

  • a passa de 7 para 8 por causa de a += 1.
  • a / b usa dois inteiros e produz 3 (mesmo sendo armazenado em um double).
  • a / 2.0 inclui um valor decimal e produz 3.5.

📌 Quatro ideias para levar da aula

  • = armazena o resultado da direita na variável da esquerda.
  • O tipo dos operandos influencia o resultado de uma expressão.
  • cin recebe dados e cout apresenta resultados.
  • Um programa sequencial segue entrada, processamento e saída.

🧩 Prática extra: total de compra

Leia preço e quantidade e mostre o total com duas casas decimais.

double preco; int quantidade; cin >> preco >> quantidade; double total = preco * quantidade; cout << fixed << setprecision(2) << total;

Gabarito: inclua <iomanip> para usar fixed e setprecision(2).

Prática online opcional: beecrowd ou C++ Shell.
