Uma condicional transforma uma pergunta em uma escolha do programa.

☝️ If: uma ação opcional

if (nota >= 60) { cout << "Aprovado" << '\n'; }

Se for verdadeira

Executa o bloco entre chaves.

Se for falsa

Ignora o bloco e segue para o próximo comando.

Boa prática: use chaves { } mesmo com uma única instrução. O código fica mais seguro e legível.

🔀 If-else: dois caminhos

if (numero % 2 == 0) { cout << "Par" << '\n'; } else { cout << "Ímpar" << '\n'; }

Condição

numero % 2 == 0

Verdadeiro

Executa o bloco do if.

Falso

Executa o bloco do else.

Depois da escolha, o programa continua no próximo comando.

🪜 Else if e aninhamento

if (nota >= 90) { cout << "Conceito A"; } else if (nota >= 60) { cout << "Aprovado"; } else { cout << "Reprovado"; }
  • As condições são testadas de cima para baixo.
  • O primeiro bloco verdadeiro é executado.
  • Uma condicional aninhada fica dentro de outra e precisa de uma nova pergunta clara.

Ordem importa: coloque primeiro as condições mais específicas.

🔗 Operadores lógicos na prática

and

Todas as condições devem ser verdadeiras.

or

Basta uma condição ser verdadeira.

not

Inverte o resultado da condição.

if (nota >= 60 and frequencia >= 75) { cout << "Aprovado"; }

A aprovação exige nota suficiente e frequência suficiente.

🎛️ Switch-case: escolhas por valor

switch (opcao) { case 1: cout << "Cadastrar"; break; case 2: cout << "Consultar"; break; default: cout << "Opção inválida"; }

case

Define o que fazer para cada valor.

default

Trata os valores que não correspondem a nenhum caso.

break

Evita executar os case seguintes.

Use switch com valores discretos, como int ou char. Para caracteres, use aspas simples: case '+':.

⚠️ Três cuidados importantes

01. Booleanos

Zero é falso; qualquer valor diferente de zero é verdadeiro. Prefira valor != 0.

02. Ponto flutuante

Evite igualdade exata após cálculos: abs(a - b) <= 0.000001.

03. Curto-circuito

Com and, um falso pode encerrar a avaliação; com or, um verdadeiro pode encerrá-la.

🧩 Desafio: classificar uma idade

Leia uma idade e informe a faixa correspondente:

Criança

Menor que 12 anos.

idade < 12

Adolescente

De 12 até 17 anos.

idade < 18

Adulto

Maior ou igual a 18 anos.

else

Dica: organize os intervalos antes de escrever as condições.

✅ Gabarito possível

int idade; cin >> idade; if (idade < 12) { cout << "Criança"; } else if (idade < 18) { cout << "Adolescente"; } else { cout << "Adulto"; }

Ideia-chave: a segunda condição só é testada se a primeira for falsa. Por isso, não foi necessário escrever idade >= 12.

🧩 Prática extra: validar uma nota

Leia uma nota e informe se ela é válida no intervalo de 0 a 100.

double nota; cin >> nota; if (nota >= 0 and nota <= 100) { cout << "Nota válida"; } else { cout << "Nota inválida"; }

Gabarito: a condição precisa combinar limite inferior e superior com and.

📌 Resumo da aula

  • Comparações produzem true ou false.
  • if, if-else e else if representam decisões.
  • and, or e not combinam condições.
  • switch-case organiza escolhas por valores discretos.
  • A ordem das condições e o break mudam o resultado.
