🎯 Vetores guardam vários valores

Um vetor é uma sequência de elementos do mesmo tipo, armazenados em posições numeradas.

int notas[5];

Tipo

int

Nome

notas

Tamanho

[5] posições

🔢 Índices começam em zero

int notas[5] = {90, 86, 54, 70, 60};

cout << notas[0]; // 90
cout << notas[4]; // 60

Em um vetor de tamanho 5, os índices válidos são 0, 1, 2, 3 e 4. Acessar notas[5] é erro.

🔁 For: repetição contada

for (int i = 0; i < 5; i++) {
    cout << notas[i] << " ";
}

Inicialização

i = 0

Condição

i < 5

Atualização

i++

⌨️ Ler e imprimir um vetor

const int N = 5;
int v[N];

for (int i = 0; i < N; i++)
    cin >> v[i];

for (int i = 0; i < N; i++)
    cout << v[i] << " ";

Use uma constante para representar o tamanho e evitar números soltos no código.

🧮 Soma, média e maior valor

int soma = 0;
int maior = v[0];

for (int i = 0; i < N; i++) {
    soma += v[i];
    if (v[i] > maior)
        maior = v[i];
}

double media = static_cast<double>(soma) / N;

Inicialize maior com o primeiro elemento quando o vetor não estiver vazio.

📚 Vetores e funções

void imprime(const int v[], int n) {
    for (int i = 0; i < n; i++)
        cout << v[i] << " ";
}

int dados[4] = {2, 4, 6, 8};
imprime(dados, 4);

Passar o vetor e seu tamanho torna a função reutilizável.

🧩 Desafio: estatísticas de notas

Leia cinco notas e informe:

  1. a média da turma;
  2. a maior nota;
  3. quantas notas são maiores ou iguais a 60.

Planeje o que precisa ser acumulado antes de escrever o for.

🧩 Prática em aula

Leia cinco notas em um vetor e mostre a maior nota, a média e a quantidade de aprovados.

Gabarito orientador: Percorra o vetor com for, use um acumulador, mantenha a maior nota e conte os valores maiores ou iguais a 60.
