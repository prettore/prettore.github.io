🧱 O que é modularização?

Modularizar é transformar uma solução grande em partes menores, chamadas funções ou subprogramas.

Entrada

Parâmetros recebidos.

Processamento

Comandos da função.

Saída

Valor retornado.

⚙️ Declaração, definição e chamada

int dobro(int valor); // declaração

int dobro(int valor) { // definição
    return 2 * valor;
}

int main() {
    cout << dobro(5); // chamada
}

A declaração informa o tipo de retorno, o nome e os tipos dos parâmetros.

🔀 Fluxo de execução

int dobro(int valor) {
    return 2 * valor;
}

int main() {
    int resultado = dobro(5);
    cout << resultado;
}
  1. main() chama dobro(5).
  2. A execução entra na função.
  3. return devolve o resultado.

🔒 Escopo: onde a variável existe?

Variável local

Declarada dentro da função. Só existe ali.

Parâmetro

Recebe um valor na chamada e funciona como variável local.

Global

Evite quando não for necessária: aumenta dependências.

Prefira passar informações por parâmetros e retornar resultados.

📦 Passagem por valor

void dobra(int x) {
    x = 2 * x;
}

int n = 5;
dobra(n);
cout << n; // continua 5

A função recebe uma cópia. Alterar o parâmetro não altera a variável original.

🔁 Troca de dois valores

void troca(int& a, int& b) {
    int aux = a;
    a = b;
    b = aux;
}

int x = 2, y = 7;
troca(x, y);

Referências são úteis quando a função precisa produzir mais de uma alteração.

📚 Vetores como parâmetros

void imprime(const int v[], int n) {
    for (int i = 0; i < n; i++)
        cout << v[i] << " ";
}

Informe o tamanho separadamente: o vetor não carrega automaticamente a quantidade de posições.

🧩 Desafio de modularização

Crie funções para:

  1. ler três notas;
  2. calcular a média;
  3. informar se o estudante foi aprovado.

Cada função deve ter uma responsabilidade clara e nomes que expliquem sua finalidade.

🧩 Prática em aula

Crie funções para ler três notas, calcular a média e informar se o estudante foi aprovado.

Gabarito orientador: Separe as responsabilidades: uma função para a média e outra para a decisão. Escolha retornos coerentes.
