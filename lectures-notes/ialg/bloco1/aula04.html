🎯 Repetir sem perder o controle

  • Executar um bloco várias vezes.
  • Escolher entre while e do-while.
  • Usar contadores, acumuladores e sentinelas.
  • Evitar repetições infinitas.

Toda repetição precisa de uma condição que possa mudar.

🔁 A ideia de um laço

1. Teste

A condição é avaliada.

2. Corpo

Os comandos são executados.

3. Atualização

Algo muda antes do próximo teste.

Pergunta-chave: o que fará a condição ficar falsa?

👀 While: testa antes

while (condicao) {
    // comandos que podem se repetir
}

Se for true

O corpo executa e o teste volta a acontecer.

Se for false

O corpo pode não executar nenhuma vez.

🚪 Do-while: executa primeiro

do {
    // comandos que se repetem
} while (condicao);

O bloco acontece pelo menos uma vez. O ponto e vírgula depois da condição é obrigatório.

⚖️ While ou do-while?

EstruturaQuando testa?Mínimo de execuções
whileAntes do corpoZero
do-whileDepois do corpoUma

Escolha a estrutura que representa melhor a leitura do problema.

🧮 Contadores e acumuladores

Contador

Conta quantas vezes algo acontece.

contador++

Acumulador

Guarda um resultado parcial.

soma += valor

Inicialização

Começa antes do laço.

soma = 0

int contador = 0;
int soma = 0;
while (contador < 5) {
    soma += contador;
    contador++;
}

🛑 Sentinelas encerram a entrada

Uma sentinela é um valor especial que sinaliza o fim da leitura.

int valor, soma = 0;
cin >> valor;
while (valor != -1) {
    soma += valor;
    cin >> valor;
}
cout << soma;

-1 encerra a entrada; ele não entra na soma.

🧩 Repetições aninhadas

Um laço pode estar dentro de outro. O laço interno completa suas voltas para cada volta do laço externo.

int linha = 1;
while (linha <= 3) {
    int coluna = 1;
    while (coluna <= 4) {
        cout << "* ";
        coluna++;
    }
    cout << "\n";
    linha++;
}

Use indentação e nomes que revelem qual variável controla cada laço.

📝 Desafio: soma e média

Leia valores até receber a sentinela -1. Ao final, mostre a soma e a média dos valores válidos.

  1. Crie um acumulador para a soma.
  2. Crie um contador para a quantidade.
  3. Evite dividir por zero quando nenhum valor for informado.

Antes de programar, escreva a condição de repetição e a atualização da leitura.

🧩 Prática em aula

Leia valores até receber -1 e mostre soma, quantidade e média dos valores válidos.

Gabarito orientador: Use uma sentinela, um acumulador e um contador. Se nenhum valor for informado, não divida por zero.
