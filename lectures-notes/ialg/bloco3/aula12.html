🎯 Por que ordenar?

Ordenar é reorganizar um conjunto em ordem crescente ou decrescente. Isso facilita a leitura, a comparação e a recuperação posterior dos dados.

Notas

Menor para maior.

Nomes

Ordem alfabética.

Busca

Vetor ordenado permite busca binária.

🔄 A ideia comum

Os métodos simples percorrem o vetor, comparam elementos e fazem trocas ou deslocamentos até que a ordem desejada seja alcançada.

Comparar

Encontre elementos fora de ordem.

Reorganizar

Troque ou desloque valores.

Repetir

Continue até ordenar.

🧭 Contextualização: algoritmos que estudaremos

Algoritmos simples

Selection Sort: seleciona o menor valor do trecho restante.

Insertion Sort: insere cada chave na parte já ordenada.

Shell Sort: aplica inserções com intervalos (gaps) decrescentes.

Algoritmos eficientes

Quick Sort: particiona os dados ao redor de um pivô.

Merge Sort: divide o vetor e intercala partes ordenadas.

🧭 Contextualização: o que não abordaremos

O Bubble Sort é conhecido, mas não é necessariamente mais simples de entender do que Selection Sort ou Insertion Sort e costuma ser ineficiente para conjuntos maiores.

Neste curso: não estudaremos Bubble Sort. Evite esse método nas atividades; pratique os algoritmos definidos para cada conteúdo.

🔎 Selection Sort

Em cada posição, procure o menor elemento do trecho ainda não ordenado e coloque-o na posição correta. std::swap faz a troca; <utility> declara essa função, enquanto <algorithm> reúne algoritmos padrão como std::sort.

#include <algorithm> // algoritmos da biblioteca padrão
#include <utility>   // declara std::swap

for (int i = 0; i < n - 1; i++) {
    int menor = i;
    for (int j = i + 1; j < n; j++) {
        if (v[j] < v[menor])
            menor = j;
    }
    std::swap(v[i], v[menor]);
}

📦 Selection Sort: troca sem std::swap

Depois de encontrar o índice do menor valor, use uma variável auxiliar para não perder nenhum dos dois valores:

int aux_troca = v[i];
v[i] = v[menor];
v[menor] = aux_troca;
1. Guarde
salve v[i] em aux_troca.
2. Copie
coloque o menor valor em v[i].
3. Complete
grave o valor guardado em v[menor].

🎯 Selection Sort: fixar o menor

Amarelo destaca a comparação atual; verde marca posições fixadas. Acompanhe i, j e menor: a troca só acontece depois de examinar todo o trecho restante.

for (int i = 0; i < n - 1; i++) {
    int p = i;
    for (int j = i + 1; j < n; j++)
        if (v[j] < v[p]) p = j;
    std::swap(v[i], v[p]);
}

🧩 Selection Sort: teste de mesa

início: {7, 3, 5, 1, 4}
i=0: menor é 1; trocar com 7 → {1, 3, 5, 7, 4}
i=1: menor é 3; já está no lugar → {1, 3, 5, 7, 4}
i=2: menor é 4; trocar com 5 → {1, 3, 4, 7, 5}
i=3: menor é 5; trocar com 7 → {1, 3, 4, 5, 7}

Ideia: cada passagem fixa uma posição. O restante ainda pode mudar.

🃏 Insertion Sort

Constrói uma parte ordenada do vetor, inserindo cada novo elemento no lugar adequado.

for (int i = 1; i < n; i++) {
    int chave = v[i];
    int j = i - 1;
    while (j >= 0 and v[j] > chave) {
        v[j + 1] = v[j];
        j--;
    }
    v[j + 1] = chave;
}

🃏 Insertion Sort: deslocar e inserir

Amarelo é a chave. Se o valor anterior for maior, ele anda uma posição à direita; quando não for, colocamos a chave no espaço aberto.

for (int i = 1; i < n; i++) {
    int chave = v[i], j = i - 1;
    while (j >= 0 && v[j] > chave) {
        v[j + 1] = v[j];
        j--;
    }
    v[j + 1] = chave;
}

📌 Insertion Sort: teste de mesa

início: {7}
chave 3: desloca 7; insere antes → {3, 7}
chave 5: desloca 7; para em 3 → {3, 5, 7}
chave 1: desloca 7, 5 e 3 → {1, 3, 5, 7}
chave 4: desloca 7 e 5; para em 3 → {1, 3, 4, 5, 7}

A parte ordenada aumenta em uma posição a cada inserção.

🐚 Shell Sort: saltos maiores

O Shell Sort aplica a ideia de inserção em elementos separados por um intervalo (gap) e reduz esse intervalo ao longo do processo.

Gap grande

Move elementos distantes.

Gap menor

Refina a ordem.

Gap 1

Termina como Insertion Sort.

O resultado depende da sequência de gaps escolhida; por isso, a análise é mais complexa.

🐚 Shell Sort: algoritmo em C++

Neste exemplo, o intervalo começa em n / 2 e é dividido por dois até chegar a 1.

for (int gap = n / 2; gap > 0;
     gap /= 2) {
    for (int i = gap; i < n; i++) {
        int chave = v[i];
        int j = i;

        while (j >= gap &&
               v[j - gap] > chave) {
            v[j] = v[j - gap];
            j -= gap;
        }
        v[j] = chave;
    }
}

Com gap = 1, cada elemento é comparado ao vizinho anterior: essa última passagem funciona como Insertion Sort.

🐚 Shell Sort: trabalhar com gaps

As células amarelas ficam separadas pelo gap. Acompanhe i, j e a chave: valores maiores são deslocados; depois reduzimos o gap até 1.
