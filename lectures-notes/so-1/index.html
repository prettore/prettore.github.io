Como usar as apresentações

Navegue com ← → ou Espaço. Em telas de toque, deslize horizontalmente. Use Sumário para escolher um tópico e Visão geral para visualizar o conjunto.

Os botões A− / A+ ajustam o tamanho dos códigos. Clique em Ver resposta para conferir as atividades e nos controles das visualizações para acompanhar cada passo. Índice retorna a esta página.

As apresentações são adaptações didáticas das notas de aula. O PDF original está disponível no link ao lado de cada aula no índice.
